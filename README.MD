Hospital Patient Analytics Dashboard

An Excel dashboard analyzing patient volume, wait times, and satisfaction scores for a hospital, built using Pivot Tables and dynamic charts.

Overview
This project tracks daily hospital operations across "January (31 days)", covering:
- Number of patients seen per day
- Average patient wait time (minutes)
- Average patient satisfaction score (out of 10)

Key Insights
- 1,026 total patients treated across the month, averaging ~33 patients/day.
- Average wait time: 36.3 minutes — peaked at 43.5 minutes on Jan 8, and was lowest (27.7 min) on Jan 21.
- 'Average satisfaction score: 5.1/10' — highest on Jan 26 (10/10) and lowest on Jan 31 (1.4/10), suggesting satisfaction is inconsistent and worth deeper investigation (possible correlation with wait time or staffing on those days).
- Busiest day: 'Jan 14, with 25 patients seen**. Quietest day: **Jan 19, with 10 patients.'

Dashboard
The `Dashboard` sheet consolidates all metrics into a single view with 7 linked charts for quick, at-a-glance reporting. Individual metric sheets (Patient Count, Wait Time, Satisfaction Score) provide focused daily trend views.

Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Data aggregation and trend analysis
